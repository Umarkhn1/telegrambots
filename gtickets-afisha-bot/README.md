# АФИША — Telegram-бот кинотеатров (gtickets.uz)

Бот [@movies_releases_bot](https://t.me/movies_releases_bot): афиша фильмов кинотеатров Узбекистана
с выбором даты и кинотеатра, сеансами, ценами, **свободными местами** и уведомлениями о новинках.

## Возможности
- 🎬 **Афиша** — все фильмы на выбранную дату (данные с gtickets.uz).
- 📅 **Выбор даты** — до 5 дней вперёд.
- 🎦 **Кинотеатры** — афиша конкретного кинотеатра.
- 🎞 **Карточка фильма** — постер, жанры, возраст, формат, режиссёр, актёры, описание, рейтинг.
- 🕐 **Сеансы** — время, зал (в т.ч. VIP 👑), формат, цена и **свободные места** (🟢/🟡/🔴) в реальном времени.
- 🔔 **Уведомления** — когда в афише появляется новый фильм, бот присылает подписчикам карточку.
- 🏙 **Города** — Ташкент, Бухара, Андижан, Самарканд, Фергана.

## Стек
- Node.js 22 + [grammY](https://grammy.dev) (long polling), без нативных зависимостей.
- Хранилище — JSON-файлы (`src/data/`): подписчики и множество «виденных» фильмов.
- Фоновый поллинг афиши (по умолчанию раз в 10 мин) для детекта новинок.

## Структура
```
src/
  config.js     токен, константы, интервалы
  api.js        клиент api.gtickets.uz (кэш 90с)
  store.js      persistent JSON: пользователи + seen
  format.js     форматирование сообщений (HTML)
  keyboards.js  inline-клавиатуры
  bot.js        хендлеры, роутинг callback'ов
  notifier.js   фоновый детект новых фильмов + рассылка
  index.js      точка входа
```

## Запуск
```bash
npm install
BOT_TOKEN=... npm start          # или под pm2:
pm2 start src/index.js --name gtickets-afisha-bot
```
Токен задаётся переменной окружения `BOT_TOKEN` (обязательно).

## Управление (pm2)
```bash
pm2 logs gtickets-afisha-bot     # логи
pm2 restart gtickets-afisha-bot  # перезапуск
pm2 stop gtickets-afisha-bot     # стоп
```

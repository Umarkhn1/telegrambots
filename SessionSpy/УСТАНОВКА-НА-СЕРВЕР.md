# Установка на сервер (Ubuntu)

Распакуйте архив и залейте папку на сервер:

```bash
scp -r cinema-bot ubuntu@СЕРВЕР:/tmp/
```

Дальше на сервере, одним куском:

```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo mkdir -p /opt/cinema-bot
sudo cp -r /tmp/cinema-bot/* /opt/cinema-bot/
cd /opt/cinema-bot
sudo python3 -m venv venv
sudo ./venv/bin/pip install -r requirements.txt
sudo chmod 600 .env

sudo cp cinema-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now cinema-bot
```

Проверить, что живой:

```bash
systemctl status cinema-bot
journalctl -u cinema-bot -f
```

Перезапуск после правки `.env`:

```bash
sudo systemctl restart cinema-bot
```

## Важно

**Локальную копию выключите.** Два бота на одном токене воруют друг у друга
сообщения, и кнопки начинают срабатывать через раз:

```powershell
Get-Process pythonw | Stop-Process -Force
```

`state.json` — память бота: напоминалки, участники чатов, загруженные ролики.
Перенесёте вместе с папкой — ничего не потеряется. Не перенесёте — бот
начнёт с чистого листа, напоминалки придётся включить заново.

# cinematica-bot — @cinematica_monitoring_bot

Уведомления о сеансах [cinematica.uz](https://cinematica.uz) в Telegram.
Работает и в личке, и в группе. Без матов — вежливо просит бронировать.

## Запуск

```
python bot.py            # обычный запуск
python bot.py --selftest # проверка API и выбора мест, без Telegram
```

Настройки — в `.env` рядом с `bot.py`. Память бота — `state.json`.

## Как пользоваться

`/start` или `/new` → два раздела:

* **Сегодня в кино** — фильм уже идёт. Дата обязательна, зал и время —
  по желанию. Не выбрал зал/время → приходят все сеансы этой даты.
* **Скоро в кино** — сеансов ещё нет. Бот сообщит сразу, как они появятся,
  с залами, временем и ценами. Дальше можно оформить обычную подписку
  с фильтрами по дате/залу/времени.

`/list` — подписки, у каждой кнопка «Отключить». `/help` — справка.

После находки бот напоминает раз в час (`REMIND_SECONDS`), максимум
`MAX_REMINDERS` раз.

## Ролики к фильмам

`MOVIE_VIDEOS=948:imax.mp4` в `.env` — id фильма и файл из папки `media`.
Ролик уходит в чат вместе с карточкой сеансов. Первый раз файл заливается
в Telegram, дальше отправляется по `file_id` из `state.json` — мгновенно.

## Автобронь

**Только для `OWNER_ID`.** Остальные не видят шаг с количеством мест и не
могут нажать кнопки брони: чужая бронь занимает места и ломает сеанс всем.

Включается, когда выбраны **дата + зал + время + количество мест**.

Места выбираются по таблице `SEAT_ANCHORS` из `.env`:

```
SEAT_ANCHORS=imax:7,8,6@13.5; atmos:5,6,4@10.5; *:4,5@5
```

Слева — кусок названия зала, дальше ряды по убыванию желания и номер
центрального места. `13.5` значит «между 13 и 14»: два места → 13, 14;
четыре → 12, 13, 14, 15; блок растёт симметрично в обе стороны.

Порядок такой: сначала ровно эти места в первом ряду, потом во втором,
потом в третьем; если везде заняты — ближайшие к центру в том же порядке
рядов (не дальше полутора мест); и только если и там пусто — геометрия
зала (центр по ширине, ~62 % глубины от экрана). Так бронь не улетит
в угол зала, когда середину уже разобрали.

Дальше бот оформляет бронь
через `POST /api/v1/payment/dis` и присылает в чат ссылку на оплату.
Сайт держит места 10 минут; если никто не нажал «Я оплатил», бот
отменяет старую бронь и делает новую с новой ссылкой.

Для этого в `.env` нужен `BOOK_PHONE` — телефон, на который оформляется
бронь. Без него автобронь не включится, уведомления работают как обычно.

`CM_LOGIN`/`CM_PASSWORD` — необязательно, нужны только чтобы к брони
подтянулась скидочная карта аккаунта.

## Отметки участников

Telegram не даёт боту список участников группы. Бот запоминает
администраторов, всех, кто писал в чат, и тех, кто вступил при нём.
Чтобы он видел обычные сообщения — **сделайте бота админом группы**.

## API cinematica.uz (что используется)

| Запрос | Зачем |
|---|---|
| `GET /api/v1/movies/today` | раздел «Сегодня в кино» |
| `GET /api/v1/movies/soon` | раздел «Скоро в кино» |
| `GET /api/v1/repertory/movie/{id}/grouped` | все сеансы фильма |
| `GET /api/v1/repertory/seats/{cinema}/{hall}/{movie}/{rep}` | схема зала и свободные места |
| `POST /api/v1/payment/dis` | бронь + ссылка на оплату |
| `GET /api/v1/payment/status/{payment_id}` | статус оплаты |

Внимание: `id` фильма в `/movies/*` (например 953) и `movie_id` внутри
репертуара (10000944) — разные. Для схемы зала нужен второй.

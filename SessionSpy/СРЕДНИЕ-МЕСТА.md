# Средние места по залам

Замер: 12.08.2026. Пересчитать — `python report_seats.py`.

## Как менять

Якоря живут в `.env`, строка `SEAT_ANCHORS`. Формат: кусок названия зала, ряды по убыванию желания, после `@` — центральное место.

```
SEAT_ANCHORS=imax:7,8,6@13.5; atmos:5,6,4@10.5; *:4,5@5
```

`13.5` значит «между 13 и 14»: два места дадут 13 и 14, четыре — с 12 по 15. Правило `*` действует только на CINEMATICA; чтобы задать любимые места в зале gtickets, добавьте строку с куском его названия.
